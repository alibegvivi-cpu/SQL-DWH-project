
# 📊 Каталог данных: Золотой слой (Gold Layer)

### Обзор
**Золотой слой (Gold Layer)** — это представление данных на уровне бизнес-логики, структурированное для поддержки аналитики, построения BI-отчетности и дашбордов. Он построен по методологии многомерного моделирования (схема «Звезда» / Star Schema) и состоит из таблиц измерений (`dim_`) и таблиц фактов (`fact_`).

---

## 1. `gold.dim_customers`
**Назначение:** Хранит сведения о клиентах, обогащенные демографическими и географическими данными для сегментации и анализа аудитории.

| Имя столбца | Тип данных | Описание |
| :--- | :--- | :--- |
| **`customer_key`** | `INT` | Суррогатный ключ, уникально идентифицирующий каждую запись клиента в таблице измерений. |
| `customer_id` | `INT` | Уникальный числовой идентификатор, присвоенный каждому клиенту в CRM-системе. |
| `customer_number` | `VARCHAR(50)` | Буквенно-цифровой идентификатор клиента, используемый для сквозного отслеживания. |
| `first_name` | `VARCHAR(50)` | Имя клиента, зафиксированное в системе. |
| `last_name` | `VARCHAR(50)` | Фамилия клиента. |
| `country` | `VARCHAR(50)` | Страна проживания клиента (например, *'Australia'*). |
| `marital_status` | `VARCHAR(50)` | Семейное положение клиента (например, *'Married'*, *'Single'*). |
| `gender` | `VARCHAR(50)` | Пол клиента (например, *'Male'*, *'Female'*, *'n/a'*). |
| `birthdate` | `DATE` | Дата рождения клиента в формате `ГГГГ-ММ-ДД`. |
| `create_date` | `DATE` | Дата и время создания первоначальной записи о клиенте в системе. |

---

## 2. `gold.dim_products`
**Назначение:** Предоставляет нормализованную информацию о продуктах (товарах), их иерархии категорий и финансовых атрибутах.

| Имя столбца | Тип данных | Описание |
| :--- | :--- | :--- |
| **`product_key`** | `INT` | Суррогатный ключ, уникально идентифицирующий каждую запись продукта в таблице измерений. |
| `product_id` | `INT` | Уникальный идентификатор, присвоенный продукту для внутреннего отслеживания. |
| `product_number` | `VARCHAR(50)` | Структурированный буквенно-цифровой код продукта (артикул/SKU) для учета запасов. |
| `product_name` | `VARCHAR(50)` | Описательное наименование продукта, включая ключевые детали (тип, цвет, размер). |
| `category_id` | `VARCHAR(50)` | Уникальный идентификатор категории продукта, связывающий его с классификацией верхнего уровня. |
| `category` | `VARCHAR(50)` | Широкая классификация продукта для группировки связанных товаров (например, *Bikes*, *Components*). |
| `subcategory` | `VARCHAR(50)` | Более подробная классификация продукта внутри категории. |
| `maintenance_required`| `VARCHAR(50)` | Указывает, требуется ли продукту сервисное обслуживание (например, *'Yes'*, *'No'*). |
| `cost` | `INT` | Себестоимость или базовая цена продукта в денежных единицах. |
| `product_line` | `VARCHAR(50)` | Определенная линейка или серия продуктов, к которой относится товар (например, *Road*, *Mountain*). |
| `start_date` | `DATE` | Дата, когда продукт стал официально доступен для продажи или использования. |

---

## 3. `gold.fact_sales`
**Назначение:** Хранит транзакционные данные о продажах. Это центральная таблица фактов, используемая для расчетов бизнес-KPI (выручка, объемы, средний чек).

| Имя столбца | Тип данных | Описание |
| :--- | :--- | :--- |
| `order_number` | `VARCHAR(50)` | Уникальный буквенно-цифровой идентификатор заказа на продажу (например, *'SO54496'*). |
| **`product_key`** | `INT` | Внешний ключ (суррогатный), связывающий заказ с таблицей измерений продуктов `gold.dim_products`. |
| **`customer_key`** | `INT` | Внешний ключ (суррогатный), связывающий заказ с таблицей измерений клиентов `gold.dim_customers`. |
| `order_date` | `DATE` | Дата размещения заказа. |
| `shipping_date` | `DATE` | Дата фактической отправки заказа клиенту. |
| `due_date` | `DATE` | Срок оплаты заказа (дата, до которой должен быть произведен платеж). |
| `sales_amount` | `INT` | Общая денежная стоимость продажи для данной позиции в целых единицах валюты. |
| `quantity` | `INT` | Количество единиц продукта, заказанных в данной позиции. |
| `price` | `INT` | Цена за единицу продукта для данной позиции в целых единицах валюты. |
